## 二、聊天界面（学习前台）

- **嵌入 librechat like 的聊天服务作为学习界面。** 
- **对话即学习入口，对话触发做题，对话反向喂养知识空间。**
- **聊天记录作为用户的"轨迹森林"。** Agent 定期扫描，提取隐性薄弱点、逃避行为、话题切换等信号，写回后台数据。
- **前端嵌入 React 组件，类似 Gemini 网页版。** 用可视化增强表现力，适合 AI Infra 这类天然适合图示的领域。
可选沙箱生成：临时性演示允许 Agent 生成 HTML，放在 iframe 沙箱里。这个沙箱还可以用来执行各种代码。

## 六、RAG 与向量数据库的定位

- **RAG 在这里是必需品，不是加分项。** 国模参数小，世界知识密度不够，幻觉风险高，必须靠 RAG 把真实资料喂到嘴边。（这个真实资料应该就是切片）
- **模型只做理解和组织，知识由向量库提供。** 它不再需要凭空回忆，只需要看着材料说话。
- 这恰好把小参数模型的短板（世界知识少）补上，把长处（推理快、成本低、可并发）发挥出来。
