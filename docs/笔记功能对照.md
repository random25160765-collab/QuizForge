# 笔记功能对照：旧编辑器里的每一条，在这边怎么办

依据是 `F:\Vaults` 四个库的**实际配置**，不是"那个编辑器有什么功能"的清单 ——
只有这样，对照出来的才是"你用过什么"，而不是"要实现多少东西"。

两条实测事实决定了这件事比预想的小：

1. **四个库里只有 `Math` 留了完整配置**（`app.json` / `appearance.json` /
   `core-plugins.json` / `graph.json` / `workspace.json`），另三个只有 `app.json`。
2. **没有任何社区插件**（四个库都没有 `plugins/` 目录）→ **不需要插件兼容层**，
   要对照的只是核心功能那一层。

下面逐条对着 `Math/.obsidian/core-plugins.json` 走：**启用 21 条、未启用 10 条**。

## 一、启用的 21 条

### 原生实现（这一版做）

| 旧功能 | 配置键 | 这边怎么做 | 备注 |

| 快速切换 | `switcher` | 快速切换（按文件名跳） | |
| 图谱 | `graph` | 复用现有力导向图 | 旧 `graph.json` 的力参数可当默认值 |
| 反链 | `backlink` | 笔记页「谁引用了我」 | |
| 出链 | `outgoing-link` | 笔记页「我引用了谁」 | |
| 标签面板 | `tag-pane` | 标签面板（读 YAML `tags`） | 91 篇的 tags 全是空的 → 见 §四 |
| 属性 | `properties` | 标题下方一行内编辑元数据头 | |
| Canvas | `canvas` | 画布（A3：DOM 节点，可读可改） | |

| 书签 | `bookmarks` | 书签列表 | |

### 不适用

| 旧功能 | 配置键 | 为什么 |
|---|---|---|
| 同步 | `sync` | **本地优先**：数据就在这台机器的一个数据目录里，没有第二端要同步。原来开它多半是为了跨设备，现在这件事由"数据目录就是你的"取代 |

## 三、导入实测（`Math`，作为占位数据）

| 项 | 数量 |
|---|---|
| 笔记 | **91** 篇（`Math` 全库） |
| 画布 | 1 个（`Untitled.canvas`，内容是 2 字节的 `{}` —— 空的，要能容错） |
| 补了元数据头 | **91** 篇（实测这一库**一篇都没有**元数据头，`qf_generated: true` 标记可批量回退） |
| 被引用附件 | 10 个 / 8.5 MB（2 张图 + 8 份 PDF） |
| 未引用附件 | **359** 个 / 690.5 MB —— 只列清单，不搬（源目录不动） |
| 跳过 | 6 个（`.obsidian/` 5 个配置 + `Untitled.base` 1 个） |
| 导入后体积 | 8.9 MB |

四个库的入口规模（供后续 `--vault` 使用）：`Math` 91 · `Personal` 26 · `Philosophy` 386 · `Tech` 610 篇。
附件总量约 3.9 GB，**按引用算只有约 147 MB**（4%）—— 这就是"附件按引用搬"这条规则的价值：
它决定这件事是"搬得动"还是"搬不动"。

## 四、导入时发现、还没处理的账

这些进清单（`data/notes/.import/Math.json`），不默默丢掉：

1. **9 条断链**：引用里写着 `bccc0c012…png` 这类 **hash 命名的图片**，源库里本来就没有
   （多半是当年从网页粘贴、临时文件被清掉了）。清单里有"哪篇笔记引的、指向哪个名字"。
2. **7 条指向不存在的笔记**：A2 会做成「未解析链接」提示 + 一键补齐。
3. **359 个未引用附件**（690.5 MB，主要是 `data/书库/` 下的电子书 PDF）：只列清单。
   要收进资料模块的话走 A4 的路径，而不是当笔记附件搬。
4. **91 篇的 `tags` 全空、335 篇用过双链**：这正是"多数笔记没有元数据也没有链接"的常态，
   A2 提供「模型建议标签与链接、逐条接受」的入口来补，**导入器不猜**（猜出来的标签会混进真分类里）。

## 五、其它两处实测（与笔记模块相邻，顺手记下）

* `Math/graph.json` 里有一组调过的力导向参数（`centerStrength` / `repelStrength` /
  `linkDistance` / `nodeSizeMultiplier` …）—— 图谱视图的默认值可以直接用它，不必重新调。
* `Math/snippet/`、`Math/.obsidian/` 这类目录属于编辑器自身的东西：`.obsidian` 不导入，
  `snippet` 原样当普通目录。
