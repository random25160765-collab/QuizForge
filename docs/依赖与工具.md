# 依赖与开发工具

> 这份是**盘点**（"这个项目依赖什么、钉在哪、谁在用"），不是安装说明 ——
> 安装只有一条路：`make api-venv && make web`（见 README 与 `docs/TUTORIAL.md`）。
>
> 最后更新：2026-10-02（量法见文末第九节，别凭印象改这份表）

## 零、清单在哪：一共四份，各管一段

| 清单 | 位置 | 管什么 |
|---|---|---|
| 后端依赖 | `api/requirements.txt` | 运行时，全是 `>=` 下限（不锁死小版本） |
| 构建期依赖 | `build/requirements-build.txt` | 只一条 PyInstaller，**不进运行时** |
| 前端第三方 | `tools/vendor.py` + `vendor/*/SOURCE.md` | 版本与来源；产物拷进 `api/web/assets/` |
| 大件下载 | `build/pyodide-manifest.json` · `build/embed-manifest.json` | 文件名 → sha256，首启逐个校验 |

**这个仓库刻意没有的东西**（别去补）：`pyproject.toml` / `setup.py`、`package.json` /
`node_modules`、ruff / black / mypy / flake8、pytest 插件、pytest-cov。
前端是**手写 DOM + 从 `vendor/` 拷产物**，没有 npm 依赖链；代码风格靠人，
不靠工具（`AGENTS.md` 里那几条纪律代替了 linter）。

## 二、重型 / 用到才装

| 链 | 组件（本机实体） | 何时取 |
|---|---|---|
| **本地向量** | onnxruntime-gpu **1.30.0** + nvidia-cuda-runtime 12.9.79 / cublas 12.9.2.10 / cudnn 9.26.0.51（约 1.4G，`scripts/gpu-setup.sh:68`）+ tokenizers 0.23.2 + numpy 2.5.3 | 首次检索时后台预取；模型按清单下 |
| **OCR** | rapidocr_onnxruntime 1.2.3 + opencv-python 5.0.0.93 + pillow 12.3.0 + shapely 2.1.2 + pyclipper 1.4.0 | 扫到扫描件才惰性 import（`pipeline/ocr.py:131,161`） |

→ 清单自动挑（`api/app/local_embed.py:113-136`）；OCR 那边有 CUDA 走 GPU、
`QF_OCR_CUDA=0` 强制 CPU。

## 九、怎么重新量一遍（别凭印象改上面任何一张表）

```bash
# 声明的下限与用途
cat api/requirements.txt build/requirements-build.txt

# 本机实体版本（不用 pip freeze：那份里有 50 多个传递依赖，看不出重点）
api/.venv/bin/python - <<'PY'
from importlib.metadata import version, PackageNotFoundError
for n in ("fastapi","uvicorn","sqlalchemy","pydantic","httpx","pytest",
          "onnxruntime-gpu","tokenizers","numpy","rapidocr-onnxruntime"):
    try: print(n, version(n))
    except PackageNotFoundError: print(n, "（未安装）")
PY

# 前端第三方的版本与来源
ls vendor/*/SOURCE.md && grep -n "VERSION\|version" tools/vendor.py | head -20

# 大件清单（模型 / Pyodide）与它们钉的哈希
api/.venv/bin/python -c "import json;print(json.load(open('build/embed-manifest.json'))['model'])"

# 解释器与运行时
api/.venv/bin/python -V; python3 -V; node -v
```

写进这份文件的原则和 `tools/db_ops.py` 一样：**结论要留得下来**，
下次不必再量一遍；量法变了，就把量法一起改在这儿。
