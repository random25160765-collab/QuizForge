# 业务立论：Agent 时代的知识学习

> **推导被外包，判断被涨薪。**
>
> 本文是本仓库所有设计取舍的**根据**。题库分四层、L1/L2 出满而 L3/L4 少而精、
> 大题要带分支点、关系靠解析而非标注、不引向量库——每一条都能回溯到这里。
> 拿不准某个取舍该往哪边倒时，回到本文判断。
>
> 2026-09-16

## 一、命题：稀缺性发生了迁移

过去信息稀缺、时间稀缺、算力稀缺，所以"能把东西做出来"本身是稀缺的——学习的目标是**生产能力**：
记住定义、练熟推导、能独立输出。

agent 把**边际推理成本**压到了近零。写代码、列方案、做推导、起草文档，都能以接近免费的成本获得。
于是整条流水线上，**唯一不能外包的环节剩下了验证与审读**：它对不对、它哪里不对、它用得对不对。

这和摄影之于绘画、计算器之于算术是同一个规律：工具不会消灭技能，只会**重新定价**。
绘画没有死，但"把形画准"不再是画家的入场券；算术没有死，但"算得快"不再是会计的核心竞争力。
agent 时代对学习者的定价也在重排：**推导廉价化，判断溢价化。**

而判断的前提是覆盖——你得**知道这个系统里都有什么、叫什么、什么量级、什么不能做**。
这四个东西单点都简单，但判断的失败恰恰是漏看其中一个。

## 二、审读的三个前提：名词、动词、红线

"看懂 agent 的输出"需要的不是才华，是三类**低成本但广覆盖**的东西：

- **名词**：术语。不认得名字，整段输出在你眼里就是噪音。
- **动词**：API 及其方向语义。`cb_reserve_back` 与 `cb_push_back` 不是同义词的两种写法，
  是方向相反的两个动作。agent 最常出的错就是**方向搞反**，而它藏在最顺口的句子里。
- **红线**：不变量与禁忌。红线是审读的**放大镜**——一眼看出致命错误，不用逐字抠。

关键在它们的分布形态：审读的失败不是"想不出"，而是"漏看一处"。链上任何一环认不出，判断就断在那里。
所以审读型知识是**乘法式的**——缺一个环节，整条链归零。这就是**广度优先**的根据：
它不是口味，是失败模式决定的。

## 三、"认得词就能指挥 agent" 的边界

这句话是对的，但有一个精确的上界：**认得词能让你发出指令、粗读输出；但抓不出"组合层"的错误。**

agent 的错大多不在"某个词不认识"，而在**"每个词都对、顺序或不变量错了"**。
抓住这种错，需要把十几个词按一条因果链串起来判断——这不是词汇，是**审读**（批判性阅读）。

所以：**词汇是入场券，审读是主战场。** 由此得到的不是"按比例配题"，而是**按知识点出满**：

| 层 | 干什么 | 覆盖策略 |
|---|---|---|
| **L1 + L2** | 铺名词/动词/红线；练"不混淆"与审读 | **出满**：每个有后果的知识点至少一道 |
| **L3 + L4** | 独立推导与迁移 | **少而精**：约 50 页 1 道，且必须人审 |

**四层走同一条流水线**（派工 → 出题 → 独立校验 → 统合入库），层是内容维度、不是流程维度：
一个点出哪几层由它自己的 `layers` 决定，在同一次任务里一并出，不存在"先一批、再一批"。

题量是**材料的知识点密度的函数**，不是预算。铺满知识点之后 L1/L2 占大头是**结果**；
预先规定"L1 几道 : L2 几道"的比例，是把手段当成了目标。

## 四、法式大题是度量工具，但要加一个装置

法式大题的难度是**乘法式的广度**，不是**加法式的刁钻**。坑题测"灵不光灵"，
法式大题测"你下没下过功夫"——这正是审读能力的那部分。而且它的**链式结构与 agent 协作的工作形态同构**：
读需求 → 定接口 → 实现 → 审 → 验，断点总是落在"某个名词不知道"。
所以它不是"考学校知识"，它是在模拟指挥 agent 时最常摔的那一跤。

但法式大题必须加一个装置：**分支点**（"条件改变时该往哪拐"——例如"如果缓存够大，这一问还成立吗"）。

分支点同时干两件事：**给学习者指路**（指引性），以及**让背解法的人露馅**（抗伪掌握）。
没有分支点的长链只是一次练习；有了分支点，它才同时是一张地图和一面照妖镜。

## 五、伪理解是新风险，度量要转向

过去"背题型"是个小毛病，反正最后还是自己做。现在它是**系统性风险**：
一个人可以靠词汇顺利通过大量输出，却并未真正理解。而**自信的误指挥比不会更危险**——
不会你会停下来，自以为会你会**放行错误**。

于是度量要转向：不再只测"你能做出什么"，要专门测**"你能审出什么"**。
可直接操作的指标是**审读命中率**：给一整段顺口的、agent 生成的解释或代码，
你能不能指出**错的那一句**、说出**后果是什么**。这是直接测判断，而不是靠产出间接测记忆。

## 六、知识的组织：图谱是日志，智适应用前置约束

两个容易被引偏的地方：

**关系不靠标注，也不靠向量。** 关系应该是**日志，不是项目**——由既有产出自动解析出边：
选项辨析 → 易混边，小问复用 → 前置边，迁移锚点 → 迁移边，`source` → 锚定边。零额外标注。
向量数据库在这里是用错了地方：向量距离是**对称的**、只表示"像不像"，
而前置关系是**反对称的**（A 是 B 的前提，反之不成立）。用向量保留关系在概念上就不成立。

**智适应用已有的东西，零新基础设施。** 自适应 = 按每题结果更新每个知识点的掌握度，再选下一题，
这已经有掌握度公式 + SM2 复习调度。真正缺的只是**前置约束**：选 B 的题之前，若 A 未掌握就先补 A。
这只需要覆盖矩阵里的 `requires` 边 + 现有掌握度表。

## 七、推论：节奏、指标、人时、工具

1. **节奏**：广度快刷（一题几秒、批量化、做错了自动进错题本）+ 顶级题少而精
   （每周啃一道，而且**必须人审**）。
2. **指标**：把"产出分数"换成"审读命中率"；把"记住了多少"换成"不混淆的有多少"。
3. **人时**：并行出题把 token 成本压到几美元，于是真正的瓶颈全部落在**顶级题的人工精审**上——
   每一道都实实在在花掉人十几分钟。所以覆盖率可以放心出满，顶级题必须克制。
4. **工具**：错题本 + SM2（间隔重复）+ 掌握度 + 前置约束，是"自适应"的最小可行集合；
   别上向量库。

## 结语

**agent 时代，推导被外包，判断被涨薪。** 学习的正确姿势不是"把推导练得更强"，
而是"把判断练得更广、更准、更快"——

**识别先于推导，审读先于产出；认得词是入场券，看得出错才是文凭。**
