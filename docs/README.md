## 新文档该放哪一类

写之前先问一句：**它会过期吗？**

- **不会**（讲原理、取舍、做法）→ 长期文档；能并进上面四份之一就别新开一份
- **会**（讲的是"现在的进度"）→ 写进 `STATUS.md`。它已经明确了自己是
  **唯一易变的状态落点** —— 另开一份"进度.md"就是制造第二份真相
- **只对一次动作有意义**（对账清单、当天经验）→ 历史记录，命名带日期，写完不再改

## 关于命名

现在两套风格并存：四份长期文档是英文大写（`STATUS.md` 这一套），专题稿与历史记录是
中文名。**保持现状是有意的** —— `STATUS.md` / `THESIS.md` 这些名字被
README、skills、文档内部大量引用，改名的收益（好看）小于代价（一堆断链）。

中文那批里，历史记录用 `<类型>-<日期>-<主题>.md` 的写法（如
`经验-2026-09-16-图谱化改造.md`）—— 新加历史记录照这个来，日期在中间，按名字排序就是按时间排序。
