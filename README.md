# QuizForge

刷题工具。五种题型（单选 / 多选 / 填空 / 简答 / 大题），题面可混排 LaTeX 与代码块。
进度按账号存在服务端，手机和电脑接着刷同一份。

题目、考纲、知识图谱都在数据库里 —— 仓库里没有题目文件。

```bash
make env-init && make db-up && make db-restore   # 起库，灌入题库快照
make api-dev                                     # → http://127.0.0.1:8100
```

## 它想解决什么

agent 把推导的边际成本压到近零，于是**验证与审读成了不能外包的环节**。
所以这里不是"考你背得全"，而是"考你审得出"：

- **四层**（识记 / 理解 / 应用 / 迁移）——L1+L2 出满，L3+L4 少而精，且必须人审
- **知识空间**——材料 → 点 → 概念 → 关系；题挂在概念上，**缺题清单就是"下一步出什么"的依据**
- **出题流水线**——派工 → 出题 → 独立校验 → 入库。钱可忽略，人的时间才是瓶颈
